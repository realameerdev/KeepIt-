## What is KeepIt?

KeepIt is a simple personal space for keeping things you don't want to lose.

We've all saved something important somewhere — a website in a browser tab, an article in a message, an idea in a random note, an image in a gallery, or a document buried inside a downloads folder.

Then later...

**Where did I save that?**

KeepIt solves that problem by giving you one simple place to keep the things worth keeping.

No complicated productivity system.

No unnecessary features.

Just **KeepIt.**

---

## Why KeepIt?

### 01 — One place for the things that matter

Keep your important links, notes, images, documents, ideas and resources together instead of scattering them across different apps.

### 02 — Find things when you need them

Search through everything you've kept and get back to what matters without digging through old chats, screenshots or browser history.

### 03 — Keep it simple

KeepIt is intentionally simple. Find something worth keeping, save it, and come back whenever you need it.

---

## What can you keep?

KeepIt is built to handle the little things that are easy to lose.

- **Links** — Articles, websites, tutorials and resources.
- **Notes** — Ideas, thoughts and information.
- **Images** — References and visuals worth keeping.
- **Documents** — Important files you want easy access to.
- **Ideas** — Things you want to remember later.
- **Resources** — Useful information you know you'll need again.
- **Anything worth keeping** — If you don't want to lose it, KeepIt.

## Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/realameerdev/KeepIt-.git

# Navigate to project directory
cd KeepIt-

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Building for Production

```bash
npm run build
```
